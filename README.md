# 三更灵异事件 — «Дом №13»: исследование и порт

Приватный репозиторий проекта по реверс-инжинирингу и портированию J2ME-игры
**三更灵异事件** (Sāngēng Língyì Shìjiàn — «Паранормальные явления третьей стражи»),
китайской хоррор-квест-бродилки для мобильных телефонов 2008 года.

## Об игре

| | |
|---|---|
| Оригинал | 三更灵异事件 (Sangen Lingyi Shijian) |
| Разработчик | 北京无限乐游科技有限公司 (Beijing Wuxian Leyou), Пекин, 2008 |
| Жанр | 2D хоррор-квест / point-and-click-бродилка, экранная навигация по комнатам |
| CN-версия | Motorola E398, 176×208; единственный билд (JAR с jvgm.cc, см. вывод №6); код не обфусцирован |
| RU-версия | «Дом №13», неофициальный перевод V.P.K (2008); SonyEricsson K700, 240×320; код обфусцирован, коллизии переписаны, перевод вольный (изменён сюжет) |

Русское название «Дом №13» — выдумка локализаторов (из их же предыстории про пятницу 13-е).
Правильный перевод названия — «Паранормальные явления третьей стражи»: 三更 — «третья стража»
(около 23:00–01:00, «часа полуночи» в китайской традиции).

## Сборка и запуск (этапы 1–5 готовы)

Требуется JDK 21 (модули собираются toolchain'ом на язык 17; подойдёт любой
полный JDK 21 — Temurin, Arch `jdk-openjdk` и т.п.). Gradle не нужен вручную —
wrapper включён. Если `JAVA_HOME` указывает на старую Java (8/11) или JRE без
javac, toolchain сам найдёт JDK 21 в системе — но лучше всё же поправить
`JAVA_HOME` (см. раздел «Java и Gradle» ниже).

```bash
./gradlew lwjgl3:run                 # запуск с самого начала: flash -> лого -> меню -> ИГРА
                                     #   -> интро-прокрутка -> «загрузка» -> пробуждение -> игра
./gradlew core:test                  # юнит-тесты (132: вьюпорт 5, данные 6, движение 7,
                                     #   edge-walk 14, клавиши 6, текст 6, звук 10+3,
                                     #   флеш 2, меню 8+2, игра 9, сквозной 2,
                                     #   интро/пробуждение 10, инвентарь 10+1, сейф 9,
                                     #   хот-зоны 17, тексты 6, настройки 2)
./gradlew lwjgl3:run -Dhouse13.start=menu       # старт с конкретной сцены: flash|logo|menu|game
./gradlew lwjgl3:run -Dhouse13.dump=d.png -Dhouse13.dump.tick=30   # дамп кадра N-го тика
./gradlew lwjgl3:run -Dhouse13.room=4           # отладка: старт в комнате N (пост-скип)
./gradlew lwjgl3:run -Dhouse13.room=1 -Dhouse13.pos=190,100        # + позиция руки
./gradlew lwjgl3:run -Dhouse13.ending=true      # отладка: сразу титры
./gradlew lwjgl3:run -Dhouse13.script=w25,D,D,F # автотест: клавиши по одной на тик
./gradlew lwjgl3:run -Dhouse13.audio=false      # без аудио (headless/CI)
./gradlew lwjgl3:run -Dhouse13.sfx=false        # выключить реставрированные SFX
./gradlew lwjgl3:run -Dhouse13.textpack=ru-auth # отладка: старт в авторском переводе
```

Токены автотеста: `U/D/L/R` (стрелки, тап), `F` (FIRE), `Ls/Rs` (софты),
`0–9`, `wN` (пауза N тиков), `UF/DF/LF/RF` (направление+FIRE одним тиком —
хот-зоны с флагом направления), `uN/dN/lN/rN` (зажать направление на N тиков —
реальная ходьба с остановкой об стену).

### Переводы (этап 5)

Игра несёт **два пака текстов**, переключаемых в меню настроек
(«ЗВУК» → группа «Перевод», клавиши 4/6; 2/8 по-прежнему переключают звук):

| Пак | Файл | Что это |
|-----|------|--------|
| «Локализаторский» (по умолчанию) | `assets/text/ru-vpk.json` | Вольное повествование V.P.K «Дом №13» (2006): Черкизовский рынок, пятница 13-е, хоррор-концовка — дословно из RU-мидлета |
| «Авторский» | `assets/text/ru-auth.json` | Дословный перевод с китайского оригинала «三更灵异事件» (北京无限乐游, 2005): Сидзуко и сестра падают в овраг, эпилог у озера, предметы как в CN (кубик-ключ, батарейка, ключ с бубенчиком) |

- Выбор сохраняется между запусками (libGDX Preferences, ключ `textpack`);
  `-Dhouse13.textpack=...` применяется разово (для дампов), не персистится.
- JSON-паки редактируются без пересборки (правила = значения полей `Texts`);
  числовые константы тоже перекрываются — у авторского пака раскладка CN-издания
  (`HELP_ROWS: 11→7`, `ABOUT_TOP: 80→40`). Незнакомый/битый пак = вшитые значения.
- Сверка строк по коду: `python3 scripts/check_text_widths.py` (лимит бокса
  сообщений 2 строки — ловит обрезание до дампов).
- Известные подстановки в авторском паке (издания различаются) — см. `_meta`
  в `ru-auth.json`: пустой ящик (R1_KEY_GONE ← соседняя строка ком.1), роман
  «古宝魅影» сокращён до «Призрак сокровищ» (лимит бокса), имя Поливановской
  транслитерации «Сидзуко» (у V.P.K — «Шизуко»).

### Java и Gradle (если «invalid source release: 17»)

Модули объявляют `sourceCompatibility 17` + `toolchain 21`: компилятор и запуск
всегда JDK 21, даже если демон Gradle работает под старой Java. Ошибки вида
`invalid source release: 17` / `does not provide the required capabilities:
JAVA_COMPILER` означают, что компиляция шла под Java 8/11 или JRE без javac —
проверьте `./gradlew -version` (строка JVM) и `echo $JAVA_HOME`; при
необходимости `export JAVA_HOME=<путь к JDK 21>` и `./gradlew --stop`.
Машинно-локальный путь можно задать в `~/.gradle/gradle.properties`:
`org.gradle.java.home=/usr/lib/jvm/java-21-openjdk` (в репозиторий не класть).

### Управление (маппинг J2ME → десктоп)

| J2ME (оригинал) | Действие | Десктоп (порт) |
|---|---|---|
| -1/-2/-3/-4, '2'/'4'/'6'/'8' | движение руки | стрелки, WASD, цифры |
| -5 (центр) / '5' | выбор / действие | Enter, Space, Z, цифра 5 |
| -6 (левый софт) | подтверждение | F1 (все функции дублированы FIRE) |
| -7 (правый софт) | отмена / меню игры / пауза | Esc, F2, Backspace |
| '1' | инвентарь (карусель) | 1 |
| '0'–'9' | ввод кода сейфа (код 9819, подтверждение '5') | 0–9 |

В отладке (в оригинале нет): PgUp/PgDn — телепорт по комнатам, F10 — оверлей стен + хитбокса.

### Музыка и звук

OGG-пререндеры лежат в `assets/audio/`: `menu.ogg` — лого/меню (канал 0),
`mapbg.ogg` — игра (канал 4). Громкость 0.7 — порт `VolumeControl.setLevel(70)`.
Выключатель — «ЗВУК» в меню/паузе (`MySound.canSound`). На desktop при потере
фокуса окна музыка ставится на паузу (в оригинале — pauseApp).

**Реставрация SFX (этап 4).** В оригинале файлы `get.mid`/`wrong.mid`/
`correct.mid` ОТСТУТСТВОВАЛИ во всех билдах (md5-сверка; в JAR только menu+mapbg),
а вызовы `playBackMid(1..3)` не были подключены — код только останавливал эти
каналы. Мы сочинили три джингла в музыкальном языке самой игры (до-минор,
музыкальная шкатулка GM#11 + безладовый бас GM#35 + синт-струны GM#51 —
инструменты её же MIDI-файлов; `assets/audio/midi/*.mid` — канонические
исходники) и подключили их в семантических точках:

| Канал | Файл | Событие |
|---|---|---|
| 1 get | get.ogg (арпеджио Cm, 230 BPM) | каждый CreateTool — находка предмета (13 мест) |
| 2 wrong | wrong.ogg (Ab3-G3 на безладовом басу) | «Неправильное использование!» |
| 3 correct | correct.ogg (Eb-D-C + аккорд Cm) | успех пазла (freeToolByIndex, молоток по стенам, код сейфа) |

Пререндер: numpy-синтез + ffmpeg (scripts/compose_sfx.py + render_sfx.py);
джинглы можно перерендерить через SF2 пользователя (как menu/mapbg) — просто
замените три .ogg. Отключение: `-Dhouse13.sfx=false`.

## Ключевые выводы исследования

Полный отчёт: `docs/Дом_№13_отчёт_об_исследовании.docx`. Кратко:

1. **RU-версия построена из CN-кода** (идентичные баги, в т.ч. выход за границы `toolStates[31]`; мёртвый код), но существенно доработана: разрешение 240×320, Nokia FullCanvas, и главное — **движение руки-курсора переписано с нуля**: ~1300 строк хардкода `drawHand()` заменены на 18 массивов прямоугольников-стен + универсальный цикл коллизий.
2. Граф комнат (18 комнат), все пазлы, сейф (код 9819), инвентарь — полностью идентичны.
3. Сохранений нет ни в одной версии (нет RMS). Музыка: в JAR реально только 2 MIDI (menu, mapbg), SFX отсутствуют.
4. Кириллица в RU решена системным шрифтом `Font.getFont(0,0,8)` — битмап-шрифтов нет.
5. Китайские титул и «нажми любую клавишу» так и не переведены даже в RU-версии (LOGO1.png, logore.png).
6. **JAR с jvgm.cc = тот же единственный CN-билд E398**, с которого снята декомпиляция
   (наборы файлов совпадают 1-в-1). «240×320» в листинге jvgm — ошибка портала: билда
   240×320 не существовало, **всю работу 240×320 (фоны back1-15, FullCanvas, коллизии)
   сделали русские локализаторы**. CFR-декомпиляция JAR подтвердила эталонность имеющейся
   декомпиляции (374 члена класса, те же константы: сейф 9819, sleep(100)). Даты в JAR:
   старейшие файлы — оба MIDI (2005-08-04, заимствованы), финальная сборка 2008-02-20.

Словарь соответствия методов и полей CN↔RU — в worklog (`docs/worklog.md`, задача 2-code-diff):
он нужен для портирования, т.к. RU-код читаем только через «розеттский камень» CN-версии.

### Сохранённые особенности и баги оригинала (этап 4)

- **«Строки-призраки»** (Эмма/меч/скала/дворец — остатки кодбазы 古宝魅影) в m()
  недостижимы: счётчик cR не инкрементируется (всегда 310 > 320-7·di) —
  зашиты в Texts.GHOST_STRINGS как документация.
- **Сцена пробуждения** автопропускается (bE=41 зашит): тексты «Ах…/Господи…/
  Больно…» из do() недостижимы, рисуется только «загрузочная» полоса.
- **Синтетическая клавиша** «вниз» каждый тик при dp==2 (paint():
  keyPressed(56)) — рука «оседает» вниз в фазе «-Где все?».
- **Сейф**: первая набранная цифра уходит в невидимую ячейку aQ[8] (туда же
  попадает '5', открывающая диалог); подтверждение — '5' при 6-м нажатии;
  не-цифра пропускает позицию, но двигает курсор.
- **Молоток не расходуется** (cP=false без freeToolByIndex) — можно бить
  обе стены одним молотком.
- **После концовки рука исчезает навсегда** (e(): a8.try=false, никто не
  восстанавливает) — в порте восстанавливается пересозданием сцены
  (архитектурное отличие; отмечено в коде).
- **Мёртвые записи** S/ed/ck/dn/a6/am/at/ct/cs/q/cp/ds — перенесены
  комментариями, состояния не содержат.
- Каскад keyPressed гасит каналы 1–3 на каждом нажатии — в оригинале это
  были бездейственные вызовы, теперь реально обрезают джинглы (как и
  задумывалось).

## Архитектурные решения (обновлено 2026-10-14: выбран Java + libGDX)

- **Язык/платформа**: Java + libGDX (Gradle). Оригинал — Java (J2ME), поэтому порт —
  по сути транскрипция API: `Canvas`→`Screen`/`render()`, `Image`→`Texture`,
  blit+текст → `SpriteBatch`+`BitmapFont`. **JNI не требуется**: игра простая, ввод,
  аудио и графика полностью покрываются libGDX. Модули: `core/` (вся логика),
  `lwjgl3/` (десктоп), `android/` (этап 6). Код — Java 8-совместимый, сборка JDK 17.
- **Ассеты не апскейлятся** (решение зафиксировано). Рендер в логическом разрешении
  **240×320** + целочисленный масштаб в окно (nearest): ×2=480×640 … ×7=1680×2240
  (влезает в телефон 1080×2340 — почти весь экран). В libGDX: `TextureFilter.Nearest`
  + собственный `IntegerScaleViewport` (целочисленный `FitViewport`).
- **Цикл**: логика — фиксированный шаг 100 мс (10 Гц, как в оригинале: скорость руки
  50 px/с и все тайминги сохраняются), рендер — по vsync.
- **Аудио**: канонические исходники — MIDI (`menu.mid`, `mapbg.mid`, оба 2005 года);
  в сборку пререндерятся в OGG/WAV через SoundFont пользователя (.sf2 в репо не входит —
  размер/лицензии). В рантайме — только аудио libGDX; `javax.sound.midi` не используем:
  на Android его нет вообще, пререндер даёт одинаковый звук на всех платформах.
- **База логики**: RU `b.java` — координаты 240×320 (массивы коллизий `f()`/`p()`,
  hot-zones `try(int)`); читаемость — через словарь CN↔RU из worklog.
- **База ассетов**: RU 240×320 (back1-15, LOGO, меню, toolback); 63 спрайта предметов
  и MIDI идентичны во всех сборках — берутся как есть. EXTD-апскейлы не используются.
- **Машина состояний** (этап 3): сцены = `drawStatus_` оригинала: `FlashScene`(-1,
  16 тиков) → `LogoScene`(0) → `MenuScene`(1) ⇄ `GameScene`(2). Подсостояния меню
  (`menuStatus_` 0–3: главное/автор/звук/помощь), меню паузы (`GAME_CURRENT` 0–3:
  продолжить/инфо/звук/выход) — каскад клавиш перенесён из `char()`/`byte()` дословно,
  включая ремап FIRE→'5' и порядок «открытие паузы не обрабатывает её же клавиши».
  Тексты подэкранов — дословно из RU-декомпиляции (`Texts.java`, этап 5 перепишет).
- **Шрифт**: FreeType + DejaVu Sans 15px (`fonts/`, лицензия в `DejaVuSans-LICENSE.txt`)
  — заменитель системного шрифта K700 `Font.getFont(0,0,8)`; финальный шрифт — этап 5.
  Перенос строк и пейджер-скролл — порты `format()`/`drawString()` в `TextFmt`.
